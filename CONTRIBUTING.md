# Contributing

Yume is licensed under the GNU Affero General Public License, version 3
([LICENSE](LICENSE)). By contributing you agree that your contribution is
licensed under those terms, and that the maintainer may also license it,
as part of Yume, under other terms.

Keep pull requests small and describe what changed in plain words. Use the
issue forms for bugs and ideas. Report security problems privately, as
[SECURITY.md](.github/SECURITY.md) describes, never in a public issue. The
[code of conduct](.github/CODE_OF_CONDUCT.md) applies everywhere the project
meets.

If you add or update a dependency, run `node scripts/third-party-notices.mjs`
and commit the regenerated notices; CI checks them. Study
content (mnemonics, kanji stories) is not part of this repository; see
`docs/card-content.md` for its format.
